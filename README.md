# 四時・八字排盤

輸入出生資料，排出八字命盤，附上日主、十神、五行、大運流年與名詞說明。純靜態網頁，生日資料只保存在使用者自己的瀏覽器，不會上傳。

GitHub Pages 使用 main 分支的 `/docs` 目錄。

## 檔案
- `docs/terms.js`：1900–2101 年二十四節氣時刻，由 `tools/gen_terms.py` 依天文計算產生（需 `pip install pymeeus`），請勿手動修改。
- `docs/engine.js`：排盤規則，可在 Node 中執行。
- `docs/texts.js`：日主、十神、五行與名詞說明。
- `docs/app.js`、`docs/index.html`、`docs/style.css`：畫面。
- `tests/verify.js`：測試，執行 `node tests/verify.js`。

## 排盤規則
- 年柱以立春換年，月柱以「節」換月，月干依五虎遁。
- 日柱以 1970/1/1 辛巳日起算；時柱依五鼠遁。
- 晚子時（23:00 以後）的日柱預設算作隔天，可改為算作當天；時柱都依隔天的日干推算。
- 十神以日主為準；地支藏干以第一個為本氣。
- 空亡依日柱所在的旬。
- 五行統計四柱八個字，不含藏干。
- 大運：陽男陰女順推、陰男陽女逆推；出生到下一個（或上一個）節的時間，三天折合一年起運。大運年齡為虛歲。
- 在台灣出生時，依瀏覽器內建的時區資料（Asia/Taipei），把當年的夏令時間與日治時期時間換算回 UTC+8 標準時間。
- 真太陽時（選用）：依出生地經度與均時差校正，只影響日柱與時柱；換年、換月與起運仍以標準時間和節氣時刻判斷。

## 節氣
以 PyMeeus 計算太陽視黃經（完整 VSOP87，含章動與光行差），並以其 ΔT 模型換算為世界時，再轉為 UTC+8。測試會與中央氣象署公布的節氣時刻比對，差距在 1 分鐘以內。
